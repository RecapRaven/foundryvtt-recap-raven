# Contributing

This is an owner-maintained project. Please open an issue for bugs and suggestions; external pull requests are not admitted to CI. Never include credentials, private campaign material, logs containing personal data, or proprietary Foundry software.

Maintainers run `make check` before requesting review. CI admits same-repository pull requests only from repository administrators or GitHub's verified Dependabot account. Release tags must match package and manifest versions and point to a commit on main.
